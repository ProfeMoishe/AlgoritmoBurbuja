¿Qué es y cómo funciona?

El método de la burbuja es un algoritmo de ordenamiento que funciona revisando cada elemento de una lista con el siguiente, intercambiándolos de posición si están en el orden equivocado.

Es necesario revisar varias veces toda la lista hasta que no se necesiten más intercambios. Es ideal para dar nuestros primeros pasos en la lógica algorítmica.

Implementación en Python

Esta es la versión optimizada que utilizamos en clase. La variable intercambio permite detener el bucle si el vector ya quedó ordenado antes de tiempo.

def ordenamiento_burbuja(vector):
    n = len(vector)
    
    for i in range(n):
        intercambio = False
        
        # Los últimos i elementos ya están ordenados
        for j in range(0, n - i - 1):
            if vector[j] > vector[j + 1]:
                # Swap en Python
                vector[j], vector[j + 1] = vector[j + 1], vector[j]
                intercambio = True
                
        # Si no hubo intercambios, terminamos
        if not intercambio:
            break
            
    return vector

# Prueba del algoritmo
mi_vector = [64, 34, 25, 12, 22, 11, 90]
print("Vector ordenado:", ordenamiento_burbuja(mi_vector))
