¿Qué es y cómo funciona?

El método de la burbuja es un algoritmo de ordenamiento que funciona revisando cada elemento de una lista con el siguiente, intercambiándolos de posición si están en el orden equivocado.

Implementación en Python

def ordenamiento_burbuja(vector):
    n = len(vector)
    for i in range(n):
        intercambio = False
        for j in range(0, n - i - 1):
            if vector[j] > vector[j + 1]:
                vector[j], vector[j + 1] = vector[j + 1], vector[j]
                intercambio = True
        if not intercambio:
            break
    return vector
